All 5 phases implemented on 2026-05-02. Load unpacked from `src/` in Chrome developer mode.

**Browser support:** Chrome (MV3 service worker) and Firefox (MV3 event-page via `background.scripts`) as of 2026-05-06; Safari 26+ added 2026-07-26. No JS changes needed for any of them — both Firefox and Safari support the `chrome.*` namespace. See `docs/firefox-support.md` and `docs/safari-support.md`.

**Safari:** consumes the Chrome build verbatim — no third manifest. Development uses Safari 26's *Settings → Developer → Add Temporary Extension…* pointed at `dist/chrome/` (no Xcode). `scripts/safari.sh` generates an Xcode app wrapper, needed only for App Store distribution. Playback verified working on Safari 26.5 / macOS 26.5 on 2026-07-26.

**All commands are documented in `docs/commands.md`** — npm scripts, `safari.sh` flags, per-browser load targets, and CI.

**Key technical decision:** Uses `window.speechSynthesis` (Web Speech API) instead of `chrome.tts` permission — gives better voice variety and works directly in content scripts.

**Storage:** `chrome.storage.sync` — syncs across devices. Keys: `enabled`, `showPopupIcon`, `minChars`, `blockedSites[]`, `selectedVoiceName`, `pitch`, `defaultSpeed`, `speedStep`, `pillPosition`, `pillTheme`.

**Known Firefox limitation:** `onboundary` word events are unreliable in Firefox — progress bar won't update mid-playback. Everything else works.

**Build for store:** `npm install && npm run build` → generates `sonorus-chrome-v{version}.zip` and `sonorus-firefox-v{version}.zip`.

**Store assets:** `assets/` holds 3 screenshots (1280×800) and a promo tile (440×280), all 24-bit RGB with no alpha, generated by `scripts/generate-store-assets.py` (Pillow — not a repo dep, run it manually). They are **drawn mockups, not captures** — they reuse the real palette and control order from `src/`, but the Chrome Web Store expects genuine screenshots, so capture real ones before submitting. The promo tile is fine to ship as-is.

**Store submission — what's still manual:**

- Replace the mockup screenshots with real captures

- No privacy policy needed — extension collects zero user data
